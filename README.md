# Week 1: Foundations — Cleaning & Exploring the Applicant Dataset

## Project Overview
This project focuses on cleaning and exploring an applicant dataset using Python and Pandas.

## Tasks Completed
- Inspected dataset structure and data quality.
- Identified and handled missing values.
- Removed duplicate records and repeated email addresses.
- Standardized domain names and application statuses.
- Cleaned application dates and phone number formatting.
- Generated a cleaned CSV file and data quality summary.

## Tools Used
- Python
- Pandas
- Google Colab

## Files
- `applicants.csv` — Original dataset
- `applicants_cleaned.csv` — Cleaned dataset
- `Week1_Data_Cleaning_Nabia.ipynb` — Notebook containing the code and explanations

**Note:** The dataset is synthetic and created for learning purposes.
